Science 7 · Computer Science · CS1

Programs and instructions

Computers use programs to perform tasks.

Created by Dr. Lance Pedersen · Use with the Programs and Instructions Lab

Welcome students to the computer science unit. Read the understanding aloud: computers use programs to perform tasks. Ask: what is one thing a computer did for you today? (Alarm, bus fare reader, a game, a thermostat.) Every one of those ran a program. This deck follows the Programs and Instructions Lab in teaching order. Lab link: Learn tab, Lesson 1.

Learning goals

By the end of this unit, I can…

break a larger task into smaller tasks.

explain a built-in function in a sequence of block code.

create a sequence using built-in functions in block code.

compare sequences that use different functions to get the same result.

discuss ways to improve existing code.

model the input–process–output cycle.

explore different configurations of hardware and software.

Unplugged warm-up. Pairs: one student writes instructions, the other acts as the robot and follows them exactly, doing only what the words say. Expect instructions like “walk to the door”, which a real robot cannot follow. Discuss: which words were vague? How many steps? Which direction? Collect predictions, then return to them on the next slides. This leads straight into Lesson 1: a program is a list of exact instructions in a programming language.

It is written in a programming language, a language with strict rules, and a computer can run it to perform a task. The same program can be written in different languages.

CS1.K3 · CS1.K5 · Lesson 3

A function is a named block of code with one job

Name

drawSquare

Says what it does.

Input

size

The value you hand it. Also called a parameter.

Algorithm

repeat 4:
move(size)
turn(left)

The ordered steps inside.

Output

A square is drawn

The result or action.

Call it with drawSquare(3). Some functions need no inputs, like turnRight(). Some cause an action instead of giving back a value.

Science 7 · CS1 · Breaking it down

CS1.K3 and K5: a function is an organized block of code for a specific task, with a descriptive name, inputs, an algorithm and an output. Accuracy note for the teacher (CS1.K5 review flag): the lab teaches the four parts, with the more precise note that some functions take no inputs (turnRight) and some produce an action instead of returning a value (drawSquare). Inputs are also called parameters. Demo the function machine: change the size of drawSquare, then switch to add(a, b), which gives back a value. Discussion: is greet(name) output a value or an action? (It prints, so an action.) Lab link: Learn tab, Lesson 3.

CS1.K4 · Lesson 4

Built-in functions come with the language

move(2)

Moves the turtle forward 2 squares.

draw(on)

Every move after this leaves a line.

print(count)

Shows a value or message in the console.

add(count, 3)

Gives back the sum of its two inputs.

Someone already wrote and tested them. Names change from language to language, but the idea stays the same. Your own functions are built from them.

Science 7 · CS1 · Breaking it down

CS1.K4 lists draw, add, print and move. Accuracy note for the teacher (CS1.K4 review flag): these are common built-in jobs whose names vary by language. In Scratch, drawing uses pen blocks and adding uses an operator block. In Python, adding usually uses the + operator and print() is a built-in function. The lab’s turtle uses the four names exactly as listed. Demo: press each block in the lab and watch the grid and console. Ask: which of these would you need to draw a snowman? Lab link: Learn tab, Lesson 4.

CS1.K5 · Lesson 5

One function, three structures

Sequence

Instructions run in order.

move(1)
move(1)
move(1)
print("At the door")

Loop

Instructions repeat.

repeat 3
move(1)
end repeat
print("At the door")

Conditional

If true, then one thing, else another.

if weather = "snow" then
print("Boots on!")
else
print("Straight outside!")

The same functions, move() and print(), appear in all three.

Science 7 · CS1 · Breaking it down

CS1.K5: functions can be used within sequences, loops and conditionals (if–then–else). Ask: the sequence and the loop both reach the door. Which would you rather write if the hallway were 30 squares long? (The loop.) For the conditional, run the lab model twice, once with the weather sensor set to snow and once set to clear. Real-life examples to sort: “Do 10 jumping jacks” (loop), “If the light is red, stop” (conditional). Lab link: Learn tab, Lesson 5; Sort It tab, Sequence, loop or conditional.

Lab Bench · Investigations 1 and 2 · CS1.S2, S3

Worked example: trace the code

count = 2
repeat 3
count = add(count, 4)
end repeat
print(count)

Line 1: count starts at 2.

Loop: add(2, 4) = 6, then add(6, 4) = 10, then add(10, 4) = 14.

Shortcut: 3 passes × 4 = 12, and 2 + 12 = 14.

print(count) shows 14.

Science 7 · CS1 · Breaking it down

CS1.S2 asks students to explain a built-in function within a sequence of block code. Model the thinking aloud: add is a built-in function, its inputs are count and 4, its output is the sum, and the = sign stores that sum back in count. Then students do randomized practice in Investigation 2 (each New program button makes a fresh one). For CS1.S3, Investigation 1 is the block code builder: four challenges (reach the flag, draw a square, draw a staircase, print 15) and a free build. In the builder, students select any block’s name to see its input, algorithm and output. Lab link: Lab Bench tab, Investigations 1 and 2.

Science 7 · CS1 · Breaking it down

CS1.S5: discuss potential improvements to existing code. Hide the right column first and ask pairs for ideas. Good improvements in this unit: descriptive names, loops instead of repeated lines, functions instead of copied code, comments, and fixing bugs then testing again. Removing the inputs makes the function work for only one pair of numbers, so it is less reusable. The lab has four review cases: long square, unclear names, wrong turn (a bug) and copied code. Part 3 · CS1.K6 to K9

How computer systems work

The IPO cycle, hardware and software, and the interfaces that connect them.

Section opener for Lessons 6 to 8 and Lab Bench Investigations 6 and 7. Lab link: Learn tab, Lesson 6.

CS1.K6 · Lesson 6 · Investigation 6

The IPO cycle: a furnace thermostat

Input

Hardware: a temperature sensor reads 18 °C.

Software: reads the sensor every few seconds.

Process

Hardware: a small processor.

Software: compares 18 °C with the 21 °C setting.

Output

Hardware: a signal turns on the furnace.

Software: controls the switch and screen.

The cycle: the room warms, the sensor reads again, and the loop repeats. At 21 °C the furnace switches off.

Storage (in many versions of the model): the saved weekday schedule.

Science 7 · CS1 · Computer systems

CS1.K6: the input–process–output (IPO) cycle models how computer systems use hardware and software to input data, process it and generate output. Edmonton winters make the furnace example familiar. Teaching note (CS1.K6 review flag): the lab teaches IPO as a cycle in which output can lead to new input, and mentions storage once because many textbooks use an input–process–output–storage model. For CS1.S6, students label three systems in Investigation 6 (school weather station, self-checkout, smart thermostat). Ask: a touch screen is both input and output. How? Lab link: Learn tab, Lesson 6; Lab Bench tab, Investigation 6.

CS1.K7: software consists of code that instructs hardware, the physical components of a computer. Quick test students can use: could you drop it on your foot? Then it is hardware. Ask: is a printer driver hardware or software? (Software.) Is a touch screen? (Hardware that is part of the user interface.) Practice: Sort It tab, Hardware or software. CS1.K8 · Lesson 7

Three types of software

System

Runs the computer itself so people can use it efficiently.

Operating systems such as Windows, macOS, ChromeOS, Android or iOS. Drivers.

Programming

Helps programmers write code.

Code editors, block coding tools, debuggers that help find errors.

Application

Helps users do tasks.

A word processor for a lab report. A spreadsheet for graphing data.

These are helpful groups. Some programs fit more than one.

Science 7 · CS1 · Computer systems

CS1.K8 names system, programming and application software. Teaching note (CS1.K8 review flag): the lab teaches the categories as helpful groups that can overlap. Operating system names are common examples, not endorsements. Stack idea from the lab model: user, then application software, then system software, then hardware, with programming software beside the stack because it is used to build the others. Ask: which type is the block coding tool you used in Investigation 1? (Programming software.) Practice: Sort It tab, Which type of software. Lab link: Learn tab, Lesson 7.

Quick check

Three questions

1

In drawSquare(4), what is the 4? Name the other three parts of this function.

2

In a self-checkout, is the barcode scanner part of the input, process or output stage?

3

Is a printer driver hardware or software? What kind of interface is it?

Science 7 · CS1 · Review

Answers. 1: The 4 is the input (parameter). The name is drawSquare, the algorithm is repeat 4 times move(size) and turn, and the output is a square drawn on the screen. 2: Input. The scanner brings data into the system; the checkout program then processes it. 3: Software. It is an interface between software and hardware, letting the computer communicate with one model of printer. Use mini whiteboards or fingers (1, 2, 3) for question 2. Extended response · Written Review

Which is better code?

Two programs draw the same square. One uses eight move and turn blocks. The other uses a repeat block or a drawSquare(size) function. Compare them and decide which is better code. Explain your reasoning.

A strong answer: says both give the same result · compares length · compares how easy each is to change · mentions reuse or a descriptive name · makes a clear choice with a reason.

Science 7 · CS1 · Review

This is Written Review extended response 1 (CS1.S4 and S5). Model answer from the lab: both programs give the same result, so both are correct. The eight-block version is long and needs four edits to change the size, so it is easy to make a mistake. The loop version is shorter and needs one edit. The function version also has a descriptive name and an input, so it can draw any size and be reused in a bigger program. Choose the function because it is the easiest to read, change and reuse. Accept other choices that are well reasoned (for example, the loop for a one-time square). Students can tick key ideas in the Written Review tab. Lab link: Written Review tab, Extended response 1.
