Long lines are wrapped onto two lines here so they fit; in a real editor each is one line. Science 9 · CS1 · Blocks and text

Key idea (CS1.K2): text languages provide greater control over how programs are designed. Teach this as setting exact details and using files, libraries and many ways to organize data. Some block tools, such as Microsoft MakeCode, can switch between blocks and text, which makes them a good bridge. Lab flag: “greater control” is taught with the trade-off on the next slide. Lab link: Learn tab, Lesson 2, Control explorer. Each job shows a short Python example.

The trade-off · CS1.K2

More control means more ways to make mistakes.

Blocks only fit where they are allowed. In text, you follow every rule yourself.

Statement slide. Discuss: why do many students start with blocks? (Fewer syntax errors, quick results.) Why do professional programmers use text? (Control, libraries, very large programs.) Both answers are right: this is a trade-off, not a winner. Lab link: Learn tab, Lesson 2, the “Ease of starting” job.

Key idea (CS1.K4): syntax is a set of rules that governs how symbols are arranged, and each language has its own. Point out what is common: all three use quotation marks for strings, parentheses for function calls, and == to compare. Return to the hook: the answer was C, a syntax error. A computer cannot guess what you meant. The third example is technically a name error rather than a syntax error, but it shows that capital letters matter. Lesson 4 · CS1.K3 · CS1.S1

Structure: indentation or braces

Python

if temp < -20:
    print("Indoor recess")
else:
    print("Outdoor recess")

Indentation is part of the syntax. Remove it and Python gives an IndentationError.

JavaScript

if (temp < -20) {
  console.log("Indoor recess");
} else {
  console.log("Outdoor recess");
}

Braces show the structure. Indentation only helps people read it.

Science 9 · CS1 · Syntax, structure, complexity

Key idea (CS1.K3, structure): block code shows structure with C-shaped blocks; text uses symbols. Ask: which block shape matches the Python colon and indent? (The C-shaped if block.) Demo in the lab: press “Remove indentation”. Python stops with IndentationError: expected an indented block after 'if' statement; JavaScript still runs but is hard to read. Lab link: Learn tab, Lesson 4, Indentation test.

Part 3 · CS1.K5 · CS1.S2 · CS1.S3 · CS1.S5

Plan, convert, explain

Pseudocode for planning, then turning blocks into text and reading code line by line.

Section opener. Ask: before you build something (a ski trip packing list, a group project), do you plan first? Pseudocode is that plan for an algorithm.

Lesson 6 · CS1.K5

Pseudocode: plain words, shaped like code

Pseudocode (for people)

SET temp TO thermometer reading
IF temp < -20 THEN
    SHOW “Indoor recess”
ELSE
    SHOW “Outdoor recess”
END IF

Python (for the computer)

temp = float(input("Temp: "))
if temp < -20:
    print("Indoor recess")
else:
    print("Outdoor recess")

A step-by-step description of an algorithm. A computer does not run it, and there is no single official rule book.

Science 9 · CS1 · Plan, convert, explain

Key idea (CS1.K5): pseudocode is a step-by-step description of an algorithm that resembles the structure of a programming language. Accuracy flag: pseudocode has no single standard; capital keywords such as IF and THEN are a common convention, not a rule. Point out the line-by-line match, and that Python needs no END IF line because indentation shows the structure. The recess rule is made up for practice. Lab link: Learn tab, Lesson 6. Move the temperature slider and press Step.

Your turn · CS1.S3

Write pseudocode for a task

The task

Ask for a mark out of 100. Show “Pass” if it is 50 or more. Otherwise show “Try again”.

Check your plan

Steps are in an order a computer could follow.

Uses keywords: GET, IF, THEN, ELSE, SHOW.

Lines inside the IF are indented.

The IF has a clear END IF.

A classmate could turn it into Python.

Science 9 · CS1 · Plan, convert, explain

Give 5 minutes. One possible answer: GET mark FROM user / IF mark >= 50 THEN / indent SHOW “Pass” / ELSE / indent SHOW “Try again” / END IF. Have partners swap and check each other against the list, then convert one partner’s pseudocode into Python together. Lab link: Lab Bench, Investigation 3 (Write pseudocode). Part A orders steps; Part B has this same task and checklist, saved in the browser.

Model a trace out loud: read one line, update the variable, write the output. Ask why only 12 is printed (print is not indented, so it runs after the loop). Science 9 · CS1 · Check and wrap-up

Answers. 1: Syntax is the set of rules for how symbols, words and numbers are arranged in a language; for example a Python if line ends with a colon, Java statements end with a semicolon, or strings go in quotation marks. 2: Four times (i is 0, 1, 2, 3). 3: For people; it plans the algorithm without worrying about one language’s syntax, so it can then be written in any language. Debate · Written Review extended 3

Should every student skip blocks and start with text code?

Take a position. Support it with reasons from the lessons, and answer the other side.

A strong answer takes a clear side with accurate reasons. For blocks: fewer syntax errors, quicker results, structure is easy to see. For text: greater control, used for real complex programs, builds typing and debugging skills. Strong answers consider the other side and may suggest a bridge, such as tools that switch between blocks and text. Use a four-corners or line-up debate, then have students write the response.
